# 구매입찰과 공급사 협상에 게임이론 적용하기

## 1. 분석 목표

구매입찰과 공급사 협상은 단순히 최저가격을 선택하는 문제가 아닙니다. 경쟁사의 입찰, 공급사의 원가와 생산 여력, 납기·품질 위험, 반복 거래 가능성 등이 결과에 영향을 줍니다.

게임이론은 이러한 상호의존적 의사결정을 구조화하는 데 도움을 주지만, 데이터가 부족하면 정교한 수식도 신뢰할 수 없습니다.

## 2. 문제 유형별 후보 모형

| 상황 | 검토할 모형 | 필요한 핵심 정보 |
|---|---|---|
| 경쟁사들이 동시에 입찰 | 정적 비협조 게임 / 경매모형 | 입찰가, 낙찰 규칙, 원가 추정 |
| 경쟁사 원가·유형을 모름 | 베이지안 게임 | 유형 정의, 사전확률, 유형별 비용 |
| 구매자 제안 후 공급사 응답 | 순차 게임 / Stackelberg 모형 | 제안 순서, 대응 가능 행동, 보수 |
| 장기 공급계약과 반복 협상 | 반복게임 | 반복 횟수, 미래 거래 가치, 이탈 유인 |
| 가격 외 품질·납기까지 평가 | 다속성 조달모형 + 게임이론 | 총소유비용, 품질·납기 손실, 평가 가중치 |

## 3. 공급사 가격 인상 요구 분석 프레임

공급사가 원재료·환율·물류비를 이유로 가격 인상을 요구하는 경우, 먼저 사실과 전략적 주장을 분리해야 합니다.

### 구매자가 확인할 데이터
- 원재료 가격지수와 실제 구매 시점
- 환율 및 결제 통화
- 물류비와 운임 조건
- 공급사의 재고 및 기존 계약 조건
- 대체 공급사 인증 가능성과 전환 기간
- 현재 재고 커버리지와 설비 보수 일정
- 가격 인상분이 원가 상승과 어느 정도 연결되는지

### 게임 구조화
- 구매자 행동: 현 가격 유지 요구, 일부 인상 수용, 물량 분할, 대체 공급원 검토
- 공급사 행동: 기존 가격 유지, 인상 요구, 물량 축소, 납기 조정
- 불확실한 유형: 공급사의 실제 원가 충격 또는 협상력
- 보수: 구매단가뿐 아니라 공급중단 위험, 품질, 납기, 전환비용 포함

## 4. 가장 중요한 비판적 검토

- 경쟁사 낙찰가격만 있고 경쟁사의 원가·입찰전략이 없다면, 경쟁사 유형을 확정적으로 추정할 수 없습니다.
- 낙찰가 데이터만으로 경쟁사의 실제 이익률을 역산할 수 없습니다.
- 최저가 낙찰과 최적 조달은 다릅니다. 품질 불량, 공사 지연, 보수 실패 비용을 포함해야 합니다.
- 공급사가 인상 요구를 했다는 사실만으로 실제 원가 상승 폭을 알 수 없습니다.
- 한 번의 협상 결과로 반복게임의 전략을 검증할 수 없습니다.

## 5. 추천 분석 순서

1. **현상 정리:** 입찰 또는 협상 규칙과 실제 의사결정 순서를 문서화
2. **데이터 점검:** 관측값, 추정값, 미확인 정보를 분리
3. **기준선 계산:** 게임이론 없이 총비용·낙찰확률·공급위험을 계산
4. **모형 선택:** 정적·동적·불완전정보·반복게임 중 상황에 맞는 모형 선택
5. **민감도 분석:** 원가, 확률, 납기 손실, 경쟁사 반응을 바꿔 결과 확인
6. **현장 검증:** 실제 의사결정 기록과 예측 결과 비교

## 6. 다음 단계에서 필요한 실제 데이터

실제 사례 분석을 진행하려면 입찰 방식, 참여 업체 수, 낙찰 기준, 과거 입찰 데이터, 품질·납기 결과가 필요합니다. 자료가 없는 항목은 임의의 숫자로 채우지 않고 미확인 변수로 남깁니다.
