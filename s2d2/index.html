3. Sequential Stackelberg Security Game

도시는 점과 선으로 표현됩니다. 점은 공격 대상, 선은 드론이 이동할 수 있는 연결입니다. 공격자는 경로와 공격 시점을 정하고, 방어자는 관측한 공격자 위치에 반응해 다음 이동을 결정합니다.

공격 가치가 높은 노드방어 드론 예시일반 노드
G = (V, E)
Rᵃ : V → ℕ
Pᵈ : V → ℤ<0
A, D ∈ ℕ
P = 공격 드론 payload
B = 배터리 용량
읽는 법
V는 대상 노드 집합, E는 이동 가능한 연결입니다. Rᵃ(v)는 공격자가 v를 공격했을 때 얻는 보상, Pᵈ(v)는 방어자가 입는 손실(음수)입니다.
중요한 구분
P는 payload(최대 공격 횟수), Pᵈ는 defender penalty입니다. 같은 P 기호 계열이지만 의미가 다릅니다.

공격자의 경로 제약

𝒫_B = {(v₁,…,v_B) ∈ Vᴮ :
각 단계에서 인접 노드로 이동
또는 현재 노드에 머무름}

간선 이동 1회 또는 한 노드에서 체공하는 것도 배터리 1단위를 소비합니다.

𝒯_(P,B) = {I ⊆ {1,…,B} : |I| ≤ P}
𝒮ᵃ = (𝒯_(P,B) × 𝒫_B)ᴬ

공격 전략은 경로 + 경로 중 실제 공격할 시점들의 집합입니다. 공격 드론 A대 각각에 대해 전략을 지정합니다.

방어자의 순차적 전략

sᵈ = (s₁ᵈ,…,s_Bᵈ)

첫 단계 s₁ᵈ는 방어 드론들의 시작 위치를 정합니다. 이후 sₜᵈ는 현재 방어 드론 위치, 관측된 공격 드론 위치, 이미 파괴된 목표 집합을 입력받아 다음 위치를 결정하는 함수입니다.

즉 방어자는 처음 배치만 정하는 것이 아니라, 공격이 진행된 뒤 관측 정보를 이용해 움직이는 정책(policy)을 선택합니다.

숫자를 바꿔보세요: 배터리와 payload

4
최대 이동/체공 단계
2
최대 공격 횟수 (P ≤ B)

교육용 설정입니다. 논문은 B, P를 입력 파라미터로 받습니다.

4.1 Coarsening the Graph — 도시를 동네로 묶기

도시 전체 노드를 그대로 게임에 넣으면 전략 공간이 너무 커집니다. 그래서 공격 가치가 높은 노드들을 중심으로 인접한 노드를 묶어 neighborhood(동네)를 만듭니다.

δ-valuable node ⇔ Rᵃ(v) > δ
V̂ = {v̂₁,…,v̂ₖ}, v̂ᵢ ⊆ V
v̂ᵢ ∩ v̂ⱼ = ∅ (i ≠ j)
δ는 공격 보상의 컷오프입니다. δ가 올라가면 Rᵃ(v) ≤ δ인 노드는 중요 대상에서 제외되고, 클러스터링 대상 노드가 줄어듭니다.

δ보다 큰 보상을 가진 노드만 핵심 노드로 표시합니다.

6
핵심 노드 수 (예제 데이터 기준)
보상 높은 노드보상 중간 노드일반 노드

왜 δ를 이진 탐색하나?

1δ를 정하고 δ-valuable 노드를 추립니다.
2가치 있는 노드 사이 거리가 배터리 B보다 커지는 클러스터 경계를 찾습니다.
3동네 수, 동네 안의 공격 보상 수, 방어 효과 등 4가지 조건을 검사합니다.
4조건이 충족되면 더 작은 δ를 탐색하고, 충족되지 않으면 δ를 높입니다.
Algorithm 2 핵심 검사
① |V̂| ≥ 4 max{A,D} (구현상 조건)
② 각 동네의 δ-valuable node 수 ≤ P
③ best-path(v̂,δ) ≤ B
④ 방어자 존재가 공격자·방어자 효용에 충분한 영향을 줌
논문은 조건을 만족하는 δ-coarsening을 찾지 못해도 멈추지 않습니다. 그 경우 penalty를 가중치로 둔 weighted K-Means 휴리스틱으로 동네를 나누지만, 이때 Section 5의 이론적 보장은 적용되지 않습니다.

4.2 Single-Attacker Single-Defender — 동네 하나 안에서 풀기

각 동네마다 공격 드론 1대와 방어 드론 1대가 있다고 가정한 하위 게임을 풉니다. 다만 실제 방어 드론이 그 동네에 있을 확률은 미리 정해져 있지 않으므로 λ로 표현합니다.

u( xᵈ, sᵃ, λ ) = λ · u( xᵈ, sᵃ )
　　　　　　　　 + (1−λ) · u( ⊥, sᵃ )
λ는 “이 동네에 방어 드론이 존재할 확률”입니다. λ=1이면 방어 드론이 반드시 있고, λ=0이면 방어 드론이 없는 상태입니다. 두 상황의 효용을 확률로 섞습니다.
50%

효용 혼합 계산 (가상 수치)

0.5×3 + 0.5×10 = 6.5
6.50
공격자 기대효용

공격 전략을 어떻게 줄이나?

uᵃ(⊥, s′ᵃ) ≤ (1−λ) · uᵃ(⊥, sᵃ)
⇒ s′ᵃ를 후보 집합에서 제거 가능

해석: 방어자가 없는 상황에서도 s′의 공격 보상이 sᵃ보다 충분히 낮다면, 방어자가 존재할 확률까지 고려한 상황에서는 s′가 최적 반응이 될 수 없습니다. 따라서 계산 후보에서 제거합니다.

후보 전략을 줄이면 계산은 빨라지지만 최적해에서 멀어질 수 있습니다. 후보 수가 임계값보다 많으면 논문은 무작위 표본을 사용합니다. 속도와 해의 품질 사이의 trade-off입니다.

방어 전략은 어떻게 줄이나?

1공격자의 가능한 경로와 공격 대상 순서를 먼저 추립니다.
2방어 드론이 각 공격 대상에 도달하는 최단 시간을 계산합니다.
3공격 시점보다 빨리 도달할 수 있는 첫 번째 방어 가능 대상을 찾습니다 (catch).
4어떤 공격 전략에도 더 늦게 대응하는 방어 전략은 지배되는 전략으로 제거합니다.
LP: max uᵈ(xᵈ, s′ᵃ, λ)
s.t. xᵈ ∈ C_D
　　 uᵃ(xᵈ,sᵃ,λ) ≤ uᵃ(xᵈ,s′ᵃ,λ) ∀sᵃ
이 LP는 “공격자가 s′ᵃ를 최적 반응으로 선택하도록 보장하면서, 방어자의 기대효용을 최대화”합니다. 공격자 후보 s′ᵃ를 바꿔가며 LP를 풀고 방어자 효용이 가장 큰 해를 고릅니다.

4.3 Meta Game — 여러 동네에 드론 배치하기

4.2에서 얻은 동네별 효용 함수를 모아, 이제 방어 드론 D대를 어느 동네에 어떤 확률로 배치할지 결정합니다. 여기서부터 동네 하나가 메타게임의 ‘표적’처럼 취급됩니다.

p̂ᵈ ∈ C_D^V̂ = {x ∈ [0,1]^|V̂| : Σᵥ̂ xᵥ̂ ≤ D}
Δ(Sᵈ) = C_D^V̂ × ∏ᵥ̂ Δ(Sᵈ_v̂)
각 동네의 보호 확률은 0~1 사이이고, 모든 동네 보호 확률의 합은 방어 드론 수 D를 넘을 수 없습니다. 이 벡터가 coverage vector입니다.
Σ λᵢ ≤ 2, 0 ≤ λᵢ ≤ 1

아래 확률은 설명을 위한 예시 배분입니다. 실제 최적해는 논문 MILP가 계산합니다.

확률적 방어 배분 예시

2.00
보호 확률 합계 (자원 한도 이내)

왜 MILP로 바꾸나?

1각 λ에서 계산한 단일 동네 효용을 점으로 얻습니다.
2점들을 연결해 조각별 선형 함수(Piecewise Linear Approximation)를 만듭니다.
3공격자는 어느 동네를 공격할지 이진변수 xₐ(v̂)로 선택합니다.
4방어자는 각 동네 보호 확률 xᵈ(v̂)를 연속변수로 결정합니다.
5공격자 최적반응 조건을 θₐ로 표현하고, 비선형 구간함수를 MILP로 선형화합니다.
max Σᵥ̂ xₐ(v̂) · ũᵈ_v̂(xᵈ(v̂))
s.t. Σᵥ̂ xₐ(v̂) = A
　　 Σᵥ̂ xᵈ(v̂) = D
　　 xₐ(v̂) ∈ {0,1}
　　 0 ≤ xᵈ(v̂) ≤ 1
　　 ũᵃ_v̂(xᵈ(v̂)) ≥ xₐ(v̂) θₐ
　　 ũᵃ_v̂(xᵈ(v̂)) ≤ (1−xₐ(v̂))θₐ + xₐ(v̂)ũᵃ_v̂(0)
목적함수는 방어자의 총 기대효용을 최대화합니다. 공격자 자원 A대는 공격 동네를 선택하고, 방어자 자원 D대는 보호 확률을 배분합니다. θₐ는 공격자 최적반응을 표현하는 임계 효용입니다.
주의: 논문은 MILP를 ‘수식 몇 개를 대입해 바로 푸는’ 방식으로 제시하지 않습니다. 동네별 하위 게임에서 얻은 비선형 효용 곡선을 조각별 선형으로 근사한 다음, 별도 이진·연속 변수를 도입해 MILP로 변환합니다.

5. Theoretical Analysis — 근사 SSE 보장

Section 5의 질문은 “S2D2가 만든 동네 분할을 따르면, 원래 게임의 최적 방어와 비교해 손실이 얼마나 커질 수 있는가?”입니다.

ε = 2 A P δ + 2 ε′

Theorem 2의 결론: δ-coarsening이 존재하고 하위 문제 오차가 ε′ 이하라면 S2D2는 ε-approximate SSE를 출력하며 ε = 2APδ + 2ε′로 상한을 제시합니다.

비판적으로 읽어야 할 점

  • 효용은 합성 분포 또는 전문가 주석에 의존하므로, 결과가 실제 공격 확률·피해 규모를 그대로 검증한 것은 아닙니다.
  • S2D2는 더 높은 방어자 효용을 얻는 대신 계산 시간이 증가합니다.
  • 이론적 δ-coarsening 조건이 충족되지 않는 현실 도시에서도 실험 성능은 좋았지만, 그 경우 정리의 보장이 자동으로 따라오지는 않습니다.
  • 실험은 특정 CPU/RAM 환경에서 수행되었으므로 다른 하드웨어에서의 실행시간을 그대로 일반화하면 안 됩니다.
