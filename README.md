# Game Theory Learning Lab

게임이론을 **정의 암기보다 상황 해석 → 수식화 → 균형 도출 → 결과 검증 → 실무 적용**의 순서로 이해하기 위한 학습 저장소입니다.

## 학습 원칙

각 주제는 다음 여섯 단계로 정리합니다.

1. **직관** — 이 개념이 필요한 이유와 해결하려는 질문
2. **상황 설정** — 경기자, 선택 가능한 전략, 정보 구조, 순서
3. **수학적 표현** — 기호, 보수(payoff), 가정
4. **도출 과정** — 최적 반응과 균형을 한 단계씩 계산
5. **숫자 예제와 검산** — 표나 트리로 계산하고 다른 전략과 비교
6. **현업 연결** — 구매입찰, 공급사 협상, 생산·설비 의사결정에 적용할 때의 한계

## 학습 경로

| 순서 | 영역 | 핵심 질문 |
|---|---|---|
| 1 | 기초 개념 | 경기자·전략·보수·정보는 무엇인가? |
| 2 | 정적 게임 | 서로의 선택을 동시에 할 때 균형은 어떻게 찾는가? |
| 3 | 불완전정보 게임 | 상대의 유형을 모를 때 어떻게 추론하는가? |
| 4 | 동적 게임 | 순차적으로 선택할 때 미래를 고려해 어떻게 결정하는가? |
| 5 | 응용 | 입찰과 공급사 협상에 어떤 모델이 적합한가? |

## 중요한 구분

- **전략(strategy)**과 **행동(action)**은 같은 말이 아닙니다. 동적 게임에서 전략은 각 의사결정 상황에 무엇을 할지 정한 완전한 계획입니다.
- **내시균형(NE)**은 일방적으로 전략을 바꿀 유인이 없는 상태입니다. 모든 참여자에게 가장 좋은 결과라는 뜻은 아닙니다.
- **베이지안 게임**은 참여자의 유형(type)에 관한 사적 정보가 존재하는 게임을 분석합니다. 유형을 모른다는 사실만으로 자동으로 베이지안 게임이 되는 것은 아니며, 유형·사전확률·보수 구조를 명시해야 합니다.
- **모형의 균형**과 **현실의 예측**은 구분해야 합니다. 결과는 가정과 데이터 품질에 민감합니다.
